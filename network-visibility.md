# Network Visibility & Connections

| Command | Description |
|---------|-------------|
| `ipconfig /all` | Display full IP configuration |
| `arp -a` | Show ARP cache entries |
| `route print` | Display the routing table |
| `netstat -ano` | Show active connections and associated PIDs |
| `nslookup example.com` | Perform DNS lookups |
| `Test-NetConnection google.com -Port 443` | Test connectivity to a host and port |
| `Get-NetTCPConnection` | List active TCP connections |
| `Get-NetIPAddress` | Display assigned IP addresses |
| `ipconfig /flushdns` | Clear DNS cache |
| `netsh winsock reset` | Reset Winsock |
| `netsh int ip reset` | Reset TCP/IP |
| `Get-Help Get-Process` | Show help for Get-Process |
